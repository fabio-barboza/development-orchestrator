# Code Quality Checklist

| Aspect | Verification |
|--------|-------------|
| Complexity | Functions not too long, low cyclomatic complexity |
| DRY | No duplicated code |
| Design | Responsibilities well separated; design principles adopted by the project followed |
| Naming | Clear and descriptive names |
| Comments | Comments only where necessary |
| Error Handling | Adequate error handling |
| Security | No obvious vulnerabilities (injection, unsafe handling of untrusted input, exposed secrets, etc.) |
| Performance | No obvious performance issues |

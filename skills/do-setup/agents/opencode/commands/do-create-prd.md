# /do-create-prd

Use a skill `do-create-prd` e execute o procedimento completo descrito nele na íntegra.

## Argumento esperado

O usuário deve fornecer o nome ou descrição da feature a ser documentada.

Se não for fornecido, **pergunte uma única vez** antes de prosseguir.

## Exemplo

```
/do-create-prd autenticação com Google
```
